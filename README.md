# Оозеки

Минималистичный тренажёр устной речи на кыргызском языке. Выбираешь категорию,
крутишь «барабан», получаешь случайную тему — и говоришь на неё под таймер.
Вдохновлён [unprompted.cool](https://unprompted.cool), но полностью на кыргызском,
с темами про Кыргызстан.

Полностью статичное SPA: без бэкенда, аналитики и аккаунтов. Настройки хранятся
в localStorage.

## Возможности

- **Два режима**: «Даярдыксыз» (быстрые бытовые темы, один таймер речи) и
  «Терең изилдөө» (аналитические темы, таймер подготовки → таймер речи).
- 10 категорий, ~225 тем + отдельные аналитические формулировки для research-режима.
- «Барабан» со звуковым перебором тем. Выбор — по принципу колоды (shuffle bag):
  тема не повторится, пока не выпадут все темы категории; колода переживает
  перезагрузку страницы (localStorage).
- Точный таймер (считает от timestamp), тихий сигнал за 10 секунд до конца
  и финальный аккорд — всё через Web Audio API, без mp3.
- Прогресс-линия: золотая, в последние 10 секунд — терракотовая.
- Настройки длительности (речь 1–10 мин, подготовка 1–60 мин) и звука.
- Горячие клавиши: `Space` — крутить тему, `Enter` — старт/стоп таймера,
  `Esc` — закрыть модалку.
- Экран не гаснет во время таймера (Screen Wake Lock API).
- Доступность: aria-атрибуты, focus-trap в модалке, `prefers-reduced-motion`.

## Стек

React 19 + TypeScript + Vite, Tailwind CSS v4, Framer Motion.
Шрифты: PT Serif + Inter (Google Fonts, cyrillic-ext — буквы **ө, ү, ң**
отображаются корректно).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка в статику (деплой на Vercel/Netlify — папка `dist`):

```bash
npm run build
npm run preview    # локальный просмотр сборки
```

## Как добавить свою категорию или темы

Все данные — в [`src/data/categories.ts`](src/data/categories.ts).

Тема — это либо строка, либо объект с русским переводом-подсказкой, который
показывается мелко под темой:

```ts
'Адаттын күчү'
{ kg: 'Терең иштөө', term: 'глубокая работа' }
```

Новая категория — ещё один элемент массива `categories`:

```ts
{
  id: 'music',                  // уникальный id (латиницей)
  label: 'Музыка',              // название в дропдауне, на кыргызском
  emoji: '🎵',
  mode: 'both',                 // 'quick' | 'research' | 'both'
  topics: [ /* 18–25 коротких тем */ ],
  researchTopics: [ /* 5–8 аналитических формулировок для режима «Терең изилдөө» */ ],
}
```

Правила подбора тем:

- `mode: 'quick'` — категория видна только в режиме «Даярдыксыз»;
  `'research'` — только в «Терең изилдөө»; `'both'` — в обоих.
- В research-режиме категория даёт все свои обычные темы плюс `researchTopics`;
  `deep-research` — отдельная категория со своим пулом.
- Категория без `researchTopics` (и не `mode: 'research'`) не показывается
  в research-режиме.

Все тексты интерфейса — в [`src/data/ui-strings.ts`](src/data/ui-strings.ts):
два объекта типа `UiStrings` (кыргызский и русский), переключатель KG/RU в
правом верхнем углу. Темы не переводятся — они всегда на кыргызском, у части
есть русская подсказка (`term`). Чтобы добавить ещё один язык, создайте третий
объект `UiStrings` и добавьте локаль в `Locale`.

## Структура

```
src/
  data/        категории, темы, все строки интерфейса
  components/  UI: шапка, переключатель режимов, дропдаун, тема, таймер, модалка
  hooks/       useTimer, useSettings, useTopicSpinner, useWakeLock
  lib/         sounds.ts — звуки через Web Audio API
```
